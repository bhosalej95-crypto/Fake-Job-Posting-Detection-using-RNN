# Fake-Job-Posting-Detection-using-RNN
Fake Job Posting Detection using RNN and NLP to classify job advertisements as genuine or fraudulent.
This project uses Recurrent Neural Networks (RNN), Long Short-Term Memory (LSTM), and Natural Language Processing (NLP) techniques to detect fraudulent job postings. The model analyzes textual information such as job titles, company profiles, job descriptions, requirements, and benefits to classify job advertisements as genuine or fraudulent.

The project includes data cleaning, handling missing values, text preprocessing, tokenization, sequence padding, and deep learning model training. RNN and LSTM architectures are used to learn patterns and contextual information from job posting text to identify potentially fraudulent advertisements.

The main objective is to help job seekers recognize suspicious job postings and reduce the risk of online recruitment fraud.

Technologies Used: Python, Pandas, NumPy, NLP, RNN, LSTM, TensorFlow/Keras, Scikit-learn, and Streamlit.
